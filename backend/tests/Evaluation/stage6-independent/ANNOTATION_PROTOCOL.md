# Prospective independent evaluation protocol

These twelve synthetic inputs are excluded from every automated benchmark and regression runner. They have not been submitted to a model or pipeline. Engineering authored the inputs; this is not real patient data or independently annotated gold.

Two independent clinical reviewers must each complete packet A or B without seeing predictions, the development failures, the other reviewer?s labels, or source code. No reviewer identity has been assigned. Obtain institutional approval before using real clinical data.

For every source mention, annotate exact name, mention_start/end and evidence_start/end (zero-based UTF-16 code units; end exclusive), evidence_quote, clinical assertion, and source-grounded attributes. Include historical, negated, conditional and allergy mentions explicitly; exclude non-order thresholds only with a documented rationale. Preserve repeated mentions as separate offset-anchored records. Distinguish product strength from administered quantity. Preserve complete PRN, weekly and dose-change instructions; do not infer route, duration or specimen from customary practice. Use null only for an explicitly reviewed absence; a missing field is unannotated. Medication fields: strength, dose, dose_unit, route, frequency, duration, formulation, instructions, action, assertion_status. Investigation fields: timing, specimen, clinical_category, assertion_status, result_value. Resolve names/views explicitly without broad organ-agnostic alias matching. Reference codes require independent terminology verification; otherwise mark not evaluated.

A third adjudicator resolves disagreements using the note and documents rationale, reviewer identifiers and timestamps. Freeze the adjudicated JSON with SHA-256 and record the implementation/artifact hashes before execution. Do not edit frozen annotations after viewing predictions; corrections require a separately versioned adjudication log. Measure entity recognition, attributes conditional on matched entities, end-to-end attribute recovery, and absent-attribute specificity separately. Do not count unannotated fields as correct. Do not authorize billable Foundry calls through this manifest.

The existing sealed-evaluation runner requires its own completed freeze manifest. These blank packets are intentionally ineligible and must never be passed to the evaluator as empty gold. Independent clinical annotation, inter-rater agreement and clinical performance results remain unavailable until the reviewers complete this process.
